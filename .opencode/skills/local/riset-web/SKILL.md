# Riset Web

Workflow wajib biar cepat dan tidak buang-buang panggilan:

## 1. Rencanakan query (1 langkah)
- Rumuskan 1–3 query pencarian pendek dan spesifik (bahasa Inggris hasilnya lebih kaya).
- Kalau butuh fakta resmi/versi → cari situs resminya langsung.
- Kalau butuh opini/jumlah banyak → pakai query lebih luas.

## 2. Cari
- Pakai tool `websearch` dulu (gratis, cepat).
- Jangan menjalankan banyak query berurutan tanpa alasan — maksimal 3 query per topik.

## 3. Baca sumber
- Untuk fakta penting, `webfetch` 1–3 URL teratas, format `markdown`, jangan semua hasil pencarian.
- Prioritaskan: dokumentasi resmi > sumber terkemuka > blog/vendor > forum.

## 4. Rangkum (format wajib)
- Jawab dalam Bahasa Indonesia, singkat, langsung ke inti.
- Akhiri dengan daftar sumber: judul singkat + URL.
- Sebutkan kalau ada ketidakpastian / info tidak ketemu — jangan mengarang.
- Kalau hasil pencarian kosong atau gagal, coba query berbeda 1x, lalu laporkan jujur bahwa pencarian tidak berhasil.
